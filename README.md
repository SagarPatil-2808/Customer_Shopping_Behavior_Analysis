📌 Overview

A complete end-to-end Customer Behavior Analysis project built using Python, MySQL, and Power BI.
The project focuses on understanding customer purchasing patterns, category performance, demographics, and subscription impact through data cleaning, EDA, SQL analytics, and dashboarding.

🗂 Dataset

File: cleaned_customer_shopping_behavior.csv

Includes:

Customer demographics

Purchase details

Product categories

Ratings & subscription status

Shipping preferences

Age group segmentation

✨ Clothing category drives the highest revenue
✨ Subscription customers spend more on average
✨ Adult & Middle Age groups show strongest purchase behavior
✨ Accessories category shows strong engagement patterns
✨ Shipping type influences overall purchase patterns
